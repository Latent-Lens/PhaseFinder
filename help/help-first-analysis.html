Your First Analysis: Step-by-Step Tutorial

A hands-on, linear tutorial guiding you from loading a bundled sample file to quality control, peak detection, model fitting, residual inspection, warning interpretation, and export.

1. Overview & Bundled Sample Data

This tutorial walks through a complete, reproducible cell-cycle analysis in PhaseFinder. Unlike reference documentation, every step here states the exact inputs, user actions, and expected numeric outcomes so you can verify your results.

Because PhaseFinder operates strictly in your browser (no server uploads), you can use the bundled synthetic FCS fixtures included in the repository:

  • Primary Tutorial Fixture: tests/validation/validation_test_data/synthetic_fcs/files/truth_clean_50_30_20.fcs
    This is a clean, balanced diploid sample generated with an exact known ground truth: 50% G1, 30% S, 20% G2/M (12,000 events total).
  • Challenging Diagnostic Fixture: tests/validation/validation_test_data/synthetic_fcs/files/arrest_g1_95_04_01.fcs
    A simulated G1-arrested sample (95% G1, 4% S, 1% G2/M) used in Section 7 to demonstrate realistic warning interpretation when a peak is nearly absent.

2. Step 1: Loading the FCS File

Launch PhaseFinder in your browser by opening the web application or running npm run dev locally.

  1. Locate the file truth_clean_50_30_20.fcs in your file browser.
  2. Drag and drop the file into the sidebar area marked Drop FCS files here (or click the area to open the file chooser).

Expected Outcome

PhaseFinder parses the FCS headers and TEXT segment instantly. A new row appears in the sample table at the bottom of the screen with:

  • Filename: truth_clean_50_30_20
  • Events: 12,000
  • Included checkbox: Checked (active for plotting)

3. Step 2: Selecting the Channel and Plotting

Before running mathematical models, inspect the raw fluorescence distribution:

  1. In the sidebar, locate the Select channel dropdown. PhaseFinder automatically identifies and selects DNA-A as the primary DNA-content channel.
  2. Click the Plot Channel Events button.

Expected Outcome

The main plot panel displays an overlaid event histogram:

  • A prominent G1 peak centered at channel ~64,000.
  • A secondary G2/M peak centered at channel ~128,000 (matching the expected 2.0× DNA ratio).
  • A distribution of intermediate values between the two peaks representing S-phase cells.
  • The plot header confirms 1 sample, 12,000 events.

4. Step 3: Pre-Modeling Quality Control (QC)

Quality control prevents flawed or unrepresentative events from corrupting model fitting. PhaseFinder uses a layered, fail-closed QC pipeline consisting of four stages:

  1. Click Cell Cycle Modeling in the sidebar. The view switches to the modeling workspace showing the Pre-modeling QC Filtering section.
  2. Click Run All to execute all four filter stages sequentially:
    • Structural QC: Rejects out-of-range, negative, or saturated sensor readings.
    • Time QC: Removes periods of unstable flow rate or optical drift.
    • Cell Gate: Isolates the primary biological population using forward and side scatter (FSC-A vs. SSC-A).
    • Singlet Gate: Distinguishes single cells from doublets and clumps using pulse geometry (DNA-A vs. DNA-W / DNA-H).

Expected Outcome

Since truth_clean_50_30_20.fcs is a clean synthetic control without artifacts:

  • All four stages display green checkmarks.
  • 0 events removed (100% retention, 12,000 / 12,000 events).
  • The filtered histogram updates automatically and is ready for peak review.

5. Step 4: Peak Identification and Review

Cell-cycle models require initial estimates of the G1 and G2/M positions. In PhaseFinder, peak boundaries define the search range and initial estimates for optimization:

  1. In the sidebar under Identify Peaks, click Detect Peaks.
  2. Inspect the suggested boundaries marked on the histogram:
    • G1 region: approximately 53,760 to 74,240.
    • G2 region: approximately 105,472 to 150,528.
  3. Click Accept to validate and lock these peak regions.

Expected Outcome

The status badge in the Identify Peaks panel changes to "Reviewed". Accepting the peak regions enables the Fit Current and Fit All Samples buttons in the Model & Fit section.

6. Step 5: Model Selection and Fitting

Now fit a mathematical cell-cycle distribution to the data:

  1. Under Model & Fit, click the model selection dropdown (initially showing Model Selection…).
  2. Select Dean–Jett.
  3. Click Fit Current.

Expected Outcome

The optimization runs in a dedicated background worker and updates the display upon completion:

  • Fitted Phase Fractions: G1 ≈ 49.1%, S ≈ 32.5%, G2/M ≈ 18.4% (recovering the planted 50 / 30 / 20 truth within 2.5 percentage points).
  • G2/G1 Ratio: ≈ 2.01 (indicating correct harmonic alignment).
  • Convergence Reason: objective_step_tolerance.
  • Status: "Reportable" (displayed in the table and plot legend).
  • Fitted curves appear over the histogram: red for G1, green/yellow for S phase, blue for G2/M, and a black line for the total model.

7. Step 6: Evaluating Fit Quality & Residuals

Never rely solely on numerical percentages; always inspect the fit quality visually using the aligned residual plot directly beneath the histogram.

  • Pearson Residuals: Each bin displays the normalized residual \( z_i = \frac{O_i - E_i}{\sqrt{E_i}} \), where \( O_i \) is the observed count and \( E_i \) is the model expectation.
  • Confidence Band: The shaded horizontal band marks the ±2 standard error threshold. Under good Poisson fit conditions, approximately 95% of residuals should lie within this band.
  • Goodness-of-Fit: The reduced deviance is approximately 1.1, close to the ideal value of 1.0.
  • Pattern Check: Residuals should be randomly scattered above and below zero without persistent runs or waves.

8. Step 7: Realistic Warning Interpretation (Arrested / Edge Cases)

A key strength of PhaseFinder is its fail-safe reporting: when data does not support a reliable fit, it flags specific diagnostic warnings rather than reporting misleading numbers with false confidence.

To see how warnings work, test the G1-arrested fixture:

  1. Load tests/validation/validation_test_data/synthetic_fcs/files/arrest_g1_95_04_01.fcs (95% G1, 4% S, 1% G2/M).
  2. Select DNA-A and click Plot Channel Events.
  3. In Cell Cycle Modeling, run QC with Run All.
  4. Click Detect Peaks. Because the G2/M peak has only ~120 events out of 12,000, the detector cannot find a distinct second peak and automatically infers G2 at 2× the G1 position. Click Accept.
  5. Select Dean–Jett–Fox and click Fit Current.

Interpreting Diagnostic Warnings

The fit completes, but PhaseFinder flags the result as Reportable with warnings (or Limited reliability):

  • Parameter at Bound: Warnings indicate that waveSigma or waveMean hit their boundary constraints (e.g. 0.02 or 0.98). With almost no S-phase events, the complex Fox polynomial cannot be properly constrained.
  • Ill-Conditioned Jacobian: High condition numbers indicate parameter colinearity (e.g. waveMean and waveSigma correlated > 0.99).
  • Restart Disagreement: Multiple optimization restarts found differing parameter combinations with nearly identical deviances.

Remediation: When encountering these warnings on low-S or arrested samples, switch to a simpler model such as Dean–Jett or Watson Classic. Fitting arrest_g1_95_04_01.fcs with Dean–Jett yields an accurate recovery (95.3% G1, 4.0% S, 0.8% G2/M) with reduced parameter instability.

9. Step 8: Exporting Results and Saving the Session

Once your analysis is complete, preserve your findings and audit trail:

  • Download Publication Graphics: Click Download in the plot controls to save SVG vector graphics or high-resolution PNG images.
  • Machine-Readable JSON: Select JSON in the export dialog to obtain a complete provenance package containing software versions, policy configuration version (policy_config_version), model parameters, standard errors, and goodness-of-fit metrics.
  • Per-Bin CSV: Export observed counts, modeled curves, and residual values for external verification in R, Python, or Prism.
  • Save Session: Click Save in the top header. This downloads a .phasefinder.toml session file. You can reload this file at any time via Load to fully restore your workspace, metadata, and fitted models.
