Troubleshooting & Compatibility

Review supported FCS inputs, browser requirements, limitations, and common recovery steps.

12. Tips, Limitations, and Troubleshooting

TopicNotes
Supported FCS inputPhaseFinder supports FCS 2.0/3.0/3.1 list-mode files with numeric F, D, or byte-aligned exact-range I DATA in declared little- or big-endian order. DNA modeling requires linear $PnE=0,0, unit/absent $PnG, one dataset, primary TEXT only, and no declared spillover involving the DNA channel. The channel selector shows this status; parser errors link to this supported-input summary, while unsupported transforms, compensation, modes, widths, supplemental TEXT, and chained datasets are blocked with a specific error.
Parameter labelsChannels shown in PhaseFinder are extracted from each parameter's $PnS label when present, falling back to $PnN, and ultimately to a generated P<n> label when needed.
No backendFiles are read entirely by browser APIs; nothing is uploaded anywhere.
State lives in memoryReloading the page clears everything that isn't saved to a session file first.
Network dependencyNone at runtime: D3 is vendored locally, and the DJF numeric implementation is repository-native.
Folder re-linking on session loadChromium browsers remember the FCS folder between sessions; Firefox and Safari will ask you to pick it again each time.
Supported browsersDesktop Chrome/Edge 111+, Firefox 121+, and Safari 16.2+. Current stable releases are recommended. OPFS and persistent folder access are optional; without them, analysis still works in memory and session reconnect uses manual file selection.
Pre-modeling QC failuresPre-modeling QC filters (Structural, Time, Cell Gate, Singlet Gate) fail closed: if a required stage rejects all events or cannot run due to missing parameters (such as missing Time or pulse-geometry channels), authoritative modeling is blocked to prevent fitting corrupted data. Review event counts in the Pre-modeling QC panel, adjust or reset gate bounds, switch Time QC methods, or uncheck unavailable optional gates.
OPFS caching & private browsingPhaseFinder uses the browser's Origin Private File System (OPFS) to cache loaded FCS files locally for instant session restore. In private/incognito browsing or browsers with strict storage partitioning, OPFS is restricted. PhaseFinder gracefully falls back to in-memory processing: analysis is unaffected, but refreshing the page requires re-selecting source files. Use Storage in the header to monitor quota, delete orphan caches, or reset stored data.
Single-peak & arrest distributionsWhen a sample displays only one prominent peak (e.g. nocodazole G2 arrest or quiescent G0/G1 cells), automated detection cannot distinguish 1C from 2C on its own and defaults to treating the peak as G1 with G2 projected at 2×. For arrested samples, verify the 1C/2C positions against an asynchronous control, manually edit the G1 and G2/M boundaries in Identify Peaks, and click Accept.
Optimizer non-convergence & warningsA fit that exceeds iteration limits or hits parameter bounds is flagged as not converged or invalid for reporting. If this occurs, inspect the histogram for unremoved debris, verify that the DNA channel is linear ($PnE=0,0$), and ensure peak limits in Identify Peaks closely bracket the true distribution peaks. If Dean–Jett–Fox overfits a simple profile, try Dean–Jett; if Dean–Jett struggles with an asymmetric S phase, try Dean–Jett–Fox.
Model comparison (AIC/BIC) prerequisitesComparing models via AIC, AICc, or BIC is valid only when candidate models are fitted to the identical dataset, identical binning, and the exact same accepted peak regions. Never adjust peak regions per-model to optimize AIC. Watson Pragmatic is a geometric decomposition without a likelihood function and cannot be compared to Dean–Jett by AIC/BIC.
